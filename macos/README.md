# Antigravity 解锁器 · macOS 简体中文版

适用于 Apple Silicon（M1 及更新芯片），最低目标系统为 macOS 13。
此包不支持 Intel Mac。

## 启动

1. 解压 `AG_2.31.2_1_macos.tar.gz`，保留整个文件夹。
2. 双击文件夹内的 **启动.command**。
3. 输入适用于上游 2.31.2 的授权密钥，然后按界面提示配置。

也可以在终端进入解压后的目录，运行 `./ag_unlocker`；运行
`./ag_unlocker --tui` 使用中文终端界面。

程序和启动脚本带有执行权限，字体已内置，无需安装额外运行库或字体。
关闭对应功能开关可撤销该功能的设置。

## macOS 首次运行提示

此公开构建使用本地临时签名（ad-hoc），没有 Apple 开发者证书或公证。
首次运行可能被 Gatekeeper 拦截。核对下载来源和 SHA-256 后，按 macOS
“系统设置 → 隐私与安全性”中的提示手动允许打开。

应用不会自动移除下载隔离标记或修改系统安全策略。
如果无法写入 Antigravity 的应用文件，按系统提示为启动它的终端授予
“App 管理”权限；具体名称取决于 macOS 版本和系统语言。

## 功能和验证范围

公开构建提供客户端补丁、DNS、本地代理、自定义 HTTP 代理和自动补丁。
不包含上游未公开的私有群组代理配置。版本密钥与 Windows 中文版一致。

发布流程在 macOS 环境中运行自动测试，并检查二进制架构、最低系统版本、
签名和压缩包权限。Apple Silicon 构建机还会检查解压后启动脚本的 `--version`
输出；Intel 构建机可交叉编译 ARM64，但不能直接运行该二进制。
本包实际构建环境及验证范围见 `BUILD-VERIFICATION.txt`。
最低系统版本是构建目标；未在 macOS 13 实机验证界面、账号登录或模型回复。

源码版本见 `SOURCE.txt`。应用许可见 `LICENSE.txt`；字体许可见
`FONT-LICENSE.txt`。更多功能说明见同目录的 `README.md`。
