# 中文字体

界面内置 Noto Sans SC Regular，比例字体优先使用它，等宽字体在缺少中文字符时回退到它。

- 来源：[Google Fonts / Noto Sans SC](https://github.com/google/fonts/tree/main/ofl/notosanssc)
- 许可证：同目录的 `OFL.txt`（SIL Open Font License 1.1）
- `NotoSansSC-Regular.ttf` 由上游 `NotoSansSC[wght].ttf` 固定字重 400 生成，保留全部字符，不依赖系统安装中文字体。
- 转换工具：fontTools `fontTools.varLib.instancer.instantiateVariableFont(font, {"wght": 400})`。

该字体许可证独立于应用自身的许可证。
